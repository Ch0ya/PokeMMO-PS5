PokeMMO

The official PokeMMO client, running as homebrew on a jailbroken PS5.

PokeMMO is a free, open-source PS5 homebrew title. It downloads the official, unmodified PokeMMO Linux client from PokeMMO's own server and runs it on the console, with the controller, the touchpad as a mouse, an on-screen keyboard and a TV-friendly setup. The game ROMs you own are preloaded into the title at build time from private/roms, so they are there on the first start.

Source and downloads on GitHub Controls

Ready menu and logs

When the client is ready, the screen shows a horizontal Start Game / Settings / Exit menu. Settings opens the start-up details and a scrollable viewer for this start's log, the previous start's log or the graphics driver log; Triangle opens the same screen at any other time. The log stays readable instead of depending on holding a button, which makes a failed start much easier to report.
